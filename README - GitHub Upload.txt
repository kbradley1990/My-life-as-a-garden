THE GARDEN OF BECOMING — ENCHANTED EDITION

LOCAL PREVIEW
1. Unzip the download.
2. Open index.html in Safari or Chrome.
3. Choose a planter and complete a reflection to see the growth celebration.
4. Use Atmosphere: On/Off to control ambient effects.
5. If you have prior progress, it will persist in the same browser if local storage origin matches.

GITHUB PAGES (existing repository)
1. Open your existing GitHub repository and choose the branch that GitHub Pages publishes (usually main).
2. Select Add file > Upload files.
3. Drag the CONTENTS of this extracted folder (index.html and all .png/.webp files) into the upload area, NOT the ZIP itself and NOT an enclosing folder.
4. Scroll down, choose Commit changes. Overwrite existing files with the same names.
5. In Actions, wait for the deployment to finish successfully. Refresh the live site using Cmd+Shift+R.
6. If old files remain, they may be unused; ensure index.html and all listed image files are uploaded together.

IMPORTANT PRIVACY NOTE
Reflections use browser localStorage only; GitHub Pages is a public static website, not a HIPAA-compliant patient portal. Do not collect protected health information here. Visitors using a shared device/browser profile may see saved reflections. Clearing browser data may erase reflections; exporting creates a plain-text file on the visitor's device.

ACCESSIBILITY
Atmospheric effects are decorative and never block planter clicks. Reduced-motion system settings disable the animation automatically. An Atmosphere button also lets visitors turn it off.
