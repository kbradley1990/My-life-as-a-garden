GITHUB UPLOAD
1. Extract the ZIP.
2. Open the extracted folder and select all files inside (not the folder itself).
3. In GitHub, open kbradley1990/my-life-as-a-garden.
4. Choose Add file > Upload files, drop the files, and Commit changes.
5. Wait for the deployment in Actions, then refresh your site in Safari (Command + Shift + R).
6. Look for the label 'The Enchanted Awakening · Version 5'. Click 'Preview Garden Awakening'.
